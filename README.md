# vibe-apps

培然同学的无用软件合集。**不会编码，硬要编码。** 每个软件都是自包含的静态小项目——点开子目录里的 `index.html` 就能玩，不用配任何环境。

在线试玩：[vibe-all.com](https://vibe-all.com/apps/)

## 作品墙

| 软件 | 一句话 | 形态 | 开发状态 | 试玩 |
|---|---|---|---|---|
| [人情债管理系统](./renqing-debt/) | 一本正经地给人情往来记账，然后告诉你这些年到底谁欠谁 | 试玩态 · 自托管态 · 私有云态 | **v1.0.0 已上线**（第一期节目作品） | [试玩](https://vibe-all.com/apps/renqing-debt/) |
| [财富密码生成器](./sample-hello/) | 一点就发财（并不会） | 试玩态 · 自托管态 | 发布流水线样例（非节目作品） | [试玩](https://vibe-all.com/apps/sample-hello/) |

## 约定

- 每个软件一个子目录，目录名 = slug
- 自包含：禁止依赖外部构建链和必须联网的 CDN
- 每个软件必须声明**形态**：**试玩态**（网站上人人可玩，关掉即还原）/ **自托管态**（下载到本地双击即用，数据留本机）/ **私有云态**（长期部署，带账号，数据在云端）
- 随便用，MIT
