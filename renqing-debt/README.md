# 人情债管理系统

一本正经地给中国式人情往来记账：谁随了多少、什么名目、什么时候，然后用金融黑话给这笔糊涂账算总账。

**形态**：试玩态（[vibe-all.com/apps/renqing-debt/](https://vibe-all.com/apps/renqing-debt/)）· 自托管态（下载本目录，双击 `index.html`）

## 两种形态

- **试玩态**（在网站上打开）：一进来就是一份编好的演示账本，随便改，**刷新或关掉即还原**，什么都不留下。
- **自托管态**（下载后双击 `index.html`）：空账本起步，数据**持久保存**在你自己的浏览器里。

形态按协议自动判断（`file://` 走自托管态，`http(s)://` 走试玩态），也可以用 `?mode=local` / `?mode=demo` 强制指定。

## 怎么用

下载本目录，双击 `index.html`——不用装任何环境，断网也能用。数据存在你自己浏览器里，不上传任何服务器；换设备用「导出数据文件 / 导入数据文件」搬家。

## 事项和备注怎么填

- **事项 = 谁办了什么事**（「我结婚」「二舅家娶媳妇」）。事由只写在这里，**只写一次**。收礼时一个事项挂一堆记录；送礼时一般一笔一个事项，录入栏可以直接打字新建。
- **备注 = 这一笔的情况**（「亲戚 · 现金」「同学 · 她妈代送的」），**不要再重复事由**。

备注下面有两组标签，点一下就填进备注：

- **关系**：亲戚 / 发小 / 朋友 / 同事 / 领导 / 同学
- **方式**：现金 / 微信转的 / 代送的 / 礼品折价

两组都能点 **＋** 自己加（比如「战友」「支付宝」），加错了点标签右边的 **×** 删掉；内置的那几个删不掉。自定义标签跟着账本一起存、一起导出。

## 想先看看效果？

点「**导入数据文件**」选本目录里的 `sample-data.json`——20 条测试数据（10 个事项、9 个关系人、跨 2018–2026、含一笔作废和两笔改动留痕），够把分页、排序、筛选、坏账、钻取全试一遍。

导进来的数据会**覆盖**当前账本；在网站上（试玩态）导入只活在这一次会话，刷新就还原。

## 四个视图

顶部页签切换 `总览 · 明细 · 关系人 · FAQ`，**录入区常驻在页签之上**（办事现场随时能录）。切页签会改 URL（`#/rows` 之类），可以直接把某一屏的链接发给别人。

- **总览**：总账四格 + 人情资产负债表 + 三张图（谁欠谁 / 逐年流水 / 关系板块）
- **明细 / 关系人**：见下
- **FAQ**：随礼常见问题（内容整理中）

## 信用评级

每个关系人有一个 **AAA / AA / A / BBB / CCC** 的评级，点姓名能看到评级依据。

评的是**账面行为**，不是人品——依据只有四样：他欠你的敞口、距上次往来多久、往来笔数、记录有没有被修正过。所以「七年前随出去、至今没下文」会掉到 CCC，「一收一送两清且还在来往」能到 AA。

## 录入快些

- **姓名自动补全**：输前两个字，从已有关系人里提示
- **金额快捷键**：200 / 500 / 600 / 800 / 1000 / 2000 一点即填
- **当日小结**：今天录了几笔、合计多少，随时能报给东家
- **撤销上一笔**：手滑了一步撤回（真删除，不留作废行；「作废」是记错了要留痕，两回事）

## 列表怎么用

两张表都是**每页 10 条**，超出后底部出现翻页；**表头点一下按这列排序，再点一下换升降序**（并列的按录入顺序，同一天录的最新一笔永远在最上面）。

- **明细**：可以搜姓名或备注，按事项、按方向（只看收到 / 只看送出）筛选，三者可叠加
- **关系人**：可以搜姓名

## 关系人

关系人表把同一个人在所有事项下的往来汇总（收到 / 送出 / 净额 / 笔数）；**点姓名**能看到这个人跨所有事项的全部往来明细与小结。

> **视觉规范见本目录的 [`DESIGN.md`](./DESIGN.md)——改样式前先读它。** 站点仓库有一份文档驱动的 token 测试钉住这些条目，漂了会红。
>
> **视觉按 Apple 设计系统**：SF Pro 字阶（正文 17px、标题负字距）、单一 Action Blue `#0066cc` 强调色、白/羊皮纸/近黑三种面、18px 圆角卡片、发丝线代替阴影（全系统零阴影）、胶囊按钮。
>
> 设计系统只有一个强调色，所以「收到 / 送出」不靠两种颜色区分——**方向由标签文字和正负号承担**，颜色只做辅助（收到 Action Blue，送出近黑）。

## 导出的 Excel

也按 [`DESIGN.md`](./DESIGN.md) 排过版：Action Blue 表头、发丝线行分隔、收/送同色规则、金额 `¥#,##0` 右对齐、作废行删除线、表头自带筛选，两个工作表（人情往来 / 关系人汇总）。
