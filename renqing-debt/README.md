# 人情债管理系统

一本正经地给中国式人情往来记账：谁随了多少、什么名目、什么时候，然后用金融黑话给这笔糊涂账算总账。

**形态**：试玩态（[vibe-all.com/apps/renqing-debt/](https://vibe-all.com/apps/renqing-debt/)）· 自托管态（下载本目录，双击 `index.html`）

## 两种形态

- **试玩态**（在网站上打开）：一进来就是一份编好的演示账本，随便改，**刷新或关掉即还原**，什么都不留下。
- **自托管态**（下载后双击 `index.html`）：空账本起步，数据**持久保存**在你自己的浏览器里。

形态按协议自动判断（`file://` 走自托管态，`http(s)://` 走试玩态），也可以用 `?mode=local` / `?mode=demo` 强制指定。

## 怎么用

下载本目录，双击 `index.html`——不用装任何环境，断网也能用。数据存在你自己浏览器里，不上传任何服务器；换设备用「导出数据文件 / 导入数据文件」搬家。

## 事项和备注怎么填

- **事项 = 谁办了什么事**（「我结婚」「二舅家娶媳妇」）。事由只写在这里，**只写一次**。收礼时一个事项挂一堆记录；送礼时一般一笔一个事项，录入栏可以直接打字新建。
- **备注 = 这一笔的情况**（「亲戚 · 现金」「同学 · 她妈代送的」），**不要再重复事由**。

备注下面有两组标签，点一下就填进备注：

- **关系**：亲戚 / 发小 / 朋友 / 同事 / 领导 / 同学
- **方式**：现金 / 微信转的 / 代送的 / 礼品折价

两组都能点 **＋** 自己加（比如「战友」「支付宝」），加错了点标签右边的 **×** 删掉；内置的那几个删不掉。自定义标签跟着账本一起存、一起导出。
